BOARDNEST QUICK START (WINDOWS)

1. Stop any currently running app with Ctrl+C in its terminal.
2. Extract this bundle into your existing BoardingHouseManagement project folder and choose to replace matching files. Back up the folder first if you have any uncommitted work.
3. Open VS Code PowerShell in the project root.
4. Create the six database tables once:
   mysql -h 127.0.0.1 -P 3306 -u boarding_house_app -p boarding_house_db
   At mysql>, run:
   source C:/Users/VladCodes/Desktop/CAPSTONE/BoardingHouseManagement/src/main/resources/db/manual/schema.sql;
   SHOW TABLES;
   exit
5. Back in PowerShell, set your DB variables (use the password you chose for the MySQL application account):
   $env:DB_URL = "jdbc:mysql://localhost:3306/boarding_house_db?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC"
   $env:DB_USERNAME = "boarding_house_app"
   $env:DB_PASSWORD = "YOUR_LOCAL_APP_PASSWORD"
6. Run:
   .\mvnw.cmd clean test
   .\mvnw.cmd spring-boot:run
7. Visit http://localhost:8080 and choose Create account. Register a NEW app account; this is not the MySQL login.

If clean test fails, copy the first [ERROR] section and send it without any passwords.
